# 郑州大学软件著作权申请流程

### 1.在中国版权保护中心官网提交材料

网址：https://www.ccopyright.com.cn/

选择我是代理人

![选择办理身份](assets/选择办理身份.png)



著作权人写郑州大学

![著作权人信息](assets/著作权人信息.png)



检查好提交材料的内容与格式

![提交材料](assets/提交材料.png)



### 2. 添加微信获取申请验证码

验证码用于官网提交之前的验证https://www.ccopyright.com.cn/

注意办理时间为周一9:00-12:00,14:30-18:00

验证码有效期24h



![ZZU软著申请微信二维码](assets/微信.jpg)

![验证码](assets/验证码.jpg)



### 3. 填写郑州大学计算机软件著作权可运行审核表

[下载审核表](附件/郑州大学计算机软件著作权可运行审核表.docx)

盖章需要去东校区国教楼113
